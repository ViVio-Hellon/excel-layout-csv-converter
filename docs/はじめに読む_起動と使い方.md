# 運用 ── 起動・停止・困ったとき

社内「汎用Webアプリ作成 基盤仕様書」に沿った作りです。ここでは**使う人と
面倒を見る人**が知っておくことだけを書きます。設計の理由はコードの先頭に
書いてあります。

## 使う

| すること | 実行するもの |
|---|---|
| 起動(デスクトップ版) | **`ExcelCsvConverter.exe`** ── 窓で動きます([docs/デスクトップ版.md](デスクトップ版.md)) |
| 起動(ブラウザ版) | **`Start.vbs`**(これ1つだけ覚えてください) |
| 停止 | `stop.bat` ── 画面の「アプリを終了」でも同じです |
| 起動しないとき | `start.bat`(診断用。黒い画面に理由が出ます) |
| 環境だけ確かめたいとき | `start.bat --check`(起動せずに構成と状態を出します) |
| いま動いているか見たいとき | `stop.bat --status`(止めません) |
| 変換中でも止めたいとき | `stop.bat --force` |

`Start.vbs` を実行すると、**同じタブに**待機画面が出て、準備ができ次第
アプリ画面へ切り替わります。**秒数で切り替えてはいません** ── バック
エンドが「自分は誰で、準備ができた」と答えてから切り替えます。待機画面も
アプリ画面も同じアドレス(`http://127.0.0.1:8741/`)なので、**2枚目の
タブは開きません**。

## 画面は1枚だけです

2枚開けると、2つの画面が同じ作業状態を奪い合います(片方で開始、もう
片方で中止。片方で保存した設定を、もう片方は古いまま表示)。どちらが
本当か分からなくなるので、**開くこと自体をお断りします**。

| やったこと | どうなるか |
|---|---|
| 同じブラウザでもう1枚開く | 開いた側が「この画面は開けません」で止まります |
| 別のブラウザで開く | 同じく断ります(サーバ側の判定) |
| URLを直接打つ | 同じく断ります |
| `Start.vbs` をもう一度実行する | 「すでに起動しています」。2つ目は起動しません |
| **画面を再読込する** | 断りません(同じタブは持ち主のままです) |
| 画面を閉じて、開き直す | 開けます(閉じたあと10秒ほどで空きます) |

画面を閉じてしまってバックエンドだけ残った場合は、`Start.vbs` をもう一度
実行すると「開き直しますか?」と聞かれます。**はい**で元の画面に戻れます。

断られた画面からは、変換も集計も設定の保存も**アプリの終了もできません**。
止められるのは、いま使っている画面と `stop.bat` だけです。

### 起動に失敗したときも `stop.bat` で止まります

フォルダの一部が欠けた・設定ファイルが壊れた・部品が無い、などで**本体を
組み立てられなかったとき**、このアプリは待機画面に理由を出したまま残り
ます(理由を読めるようにするため)。この状態でも:

- `stop.bat` で**止まります**(待機画面も停止の合図に答えます)
- `stop.bat --status` に「まだ準備できていません」と**起動の失敗の理由**が出ます
- 誰も止めなければ、**10分で自分から閉じます** ── 残っていると、その
  フォルダを消せません(配り直しはフォルダの置き換えなので、ここで詰まります)

**`stop.bat` は、止まったことを確かめてから「止まりました」と言います。**
残っていれば「まだ残っています(PID …)」と出し、終了コードも 0 にしません。

## 設定

画面上部の「設定」で決めて、保存すると**この端末に残ります**
(`%LOCALAPPDATA%\ExcelCsvConverter\data\settings.json`)。

| 項目 | 何を入れるか |
|---|---|
| 入力フォルダ | **空のままで構いません。** ドラッグで入れるなら使いません ── 変換タブで「入力フォルダをそのまま読む」を選んだときだけ、ここを読みます(共有に溜まったブックをドラッグせずに読むため) |
| 出力先フォルダ | **CSVを書く先。必須です。** 無ければ作ります |
| ライン | `LS` / `HVC` など。空ならシートの呼び名から当てます(`機側` → `LS`) |
| 参照用マスタの置き場所 | `伝送用ファイル.sqlite3` が入っているフォルダ。停止の「内訳」名に使います |
| ログの置き場所 | **空ならこの端末の中**(「ログを開く」で開きます)。共有へ集めたいときに指定します。**指した先にツール名のフォルダを作り、ファイル名もツール名から始めます**(下記)。書けない場所なら端末の中へ戻し、その理由も残します |
| 停止内訳CSVの置き場所 | **メモ帳で直せる停止理由の一覧**(`停止内訳.csv`)。フォルダでもファイルそのものでも構いません。分類ごとに、ここに行があれば**参照用マスタより先に**読みます |

**停止の「内訳」名の出どころは2つです。** どちらから読めたかは設定の下に
出ます(`停止内訳: 12記号(設備停止=CSV / 不稼働=マスタ …)`)。CSVに直す
ところがあれば、**行番号つき**で出します ── 読めない行を黙って捨てると、
一覧から理由がひっそり消えるためです。書き方は4つの欄だけです:

```
分類,内訳番号,内訳,備考
1,0,休憩食事,
2,イ,突発停止(機械),
3,A,段取り変更,
```

分類は `1`=管理ロス(記号は数字) / `2`=突発・待ち(記号は片仮名) /
`3`=ハンドリング(記号は英字)。**記号は日報に残っているものと同じに
してください** ── 変えると、昔の日報の停止が「内訳にない記号」になります。

エクスプローラーの「パスのコピー」は引用符つき(`"C:\…"`)で入りますが、
そのまま貼って構いません ── 外してから使います。入力欄の下に**実際に
見に行く場所**と、そこがあるかどうかが出ます。

## 読ませかた

- **ドラッグで放り込む** ── 画面の枠へブックを落とします。フォルダごとでも
  構いません(中の `.xlsx` / `.xlsm` を拾います)。クリックで選ぶこともできます。
  機側データ集計タブは**CSVも受けます** ── 変換が出した日付フォルダを
  そのまま落とせば、集計明細を材料に、停止内訳で名前を補って集計します
  (`docs/機側データ集計.md`)。
- **入力フォルダをそのまま読む** ── 設定した入力フォルダを読みます。
  押す前に「入力フォルダを数える」で本数を確かめられます。

**一度に100本まで。** 超えたぶんは受け取らず、その場で断ります
(`config/app.json` の `limits.max_files` で変えられます)。

> ブラウザは、放り込まれたファイルの本当の場所を教えてくれません(安全上の
> 決まり)。そのため、ドラッグのときだけ中身をいったん
> `%LOCALAPPDATA%\ExcelCsvConverter\work\intake` へ写してから読みます。
> 使い終われば消します。

変換すると、1日・1ラインにつき**5本**出ます。4本は日報管理ツールと同じもの
(集計 / 集計明細 / 停止内訳 / 計算内容)、5本目(`機側データ集計_<ライン>_<日付>.csv`)は
**機側データ集計の材料**です ── この5本目があるので、あとから日付フォルダを
集計タブへドラッグしても、**ブックから集計したのと同じ結果**になります。

**出したCSVはダウンロードしません。** 設定した出力先フォルダへ、この端末の
Pythonが直接書きます。「出力先を開く」でエクスプローラーが開きます。

## 変換中

進捗バーに「何本目か」「いま読んでいるファイル」「あとどれくらいか」が出ます。

- **中止**できるのは読み取り中だけです。CSVを書き始めてからは止めません
  ── 4本組のCSVを半分書いた状態で残すほうが危ないからです。
- 読み取り中に中止した場合、**CSVは1本も書きません**。
- ブラウザを閉じても変換は続きます。開き直すと、そのまま進み具合が出ます。
- 変換が終わって画面を30分開かないままにすると、バックエンドは自分で
  終わります(`monitoring.idle_exit_minutes`)。**変換中は終わりません。**
- **裏に回したタブ・スリープでは終わりません**(下記)。

### 自動終了は、**スリープと裏のタブでは効きません**(1.11.0)

ほかのツールで「スリープ復帰時の時計のずれやブラウザのタブ休止により
問い合わせが止まり、サーバーが誤って終了してしまう」という不具合があり、
このアプリも同じ作りでした。直してあります。

| 状態 | どうなるか |
|---|---|
| 画面が見えている | これまでどおり ── 30分 心拍が無ければ終わります |
| **裏に回っている**(最小化・ほかの窓が前面・ほかのタブ) | **終わりません。** ブラウザは見えていないタブのタイマーを間引き、Edge の「スリープ中のタブ」や Chrome のメモリセーバーは止めます。隠れる瞬間に合図を送るので、心拍が止まっても居るものとみなします(置き去りは7日で片づけます) |
| **スリープ・休止から復帰** | **終わりません。** 眠っていた時間は無通信に数えません(`converter/awake_clock.py`)。時刻合わせで時計が飛んだときも同じです |
| タブを閉じた | これまでどおり ── 20秒待って終わります(再読込なら戻ってきた心拍で取り消します) |
| 2枚目のタブだけ閉じた | **終わりません**(残った1枚で続きます) |

いま何枚居るとみなしているかは、画面下の「診断情報」に出ます
(`idle`: `screens` / `hidden`、`awake`: 眠っていた合計と最後の復帰)。

## 結果の見かた

| 印 | 意味 |
|---|---|
| ○ | 読めて、シート自身の合計とも合った |
| ! | 読めたが、**数がシートと合わない** ── 座標がずれているおそれがあります |
| × | 読めなかった(理由が同じ行に出ます) |

`!` は黙って通しません。どの直のどの数がいくつ違うかまで行に出ます。

## 困ったとき

まずログです。画面の「ログを開く」、または
`%LOCALAPPDATA%\ExcelCsvConverter\logs`。

| ファイル | 分かること |
|---|---|
| `error.log` | **うまくいかなかったことだけ。** 追うときの入口 |
| `app.log` | 画面の操作・変換の筋道(1本ごと)・集計の筋道 |
| `launcher.log` | 起動の入口。環境・多重起動の判定・終了理由 |

「起動前に失敗したのか、Webサーバが失敗したのか、変換で失敗したのか」が
この3本で分かれます。**置き場所は設定の「ログの置き場所」で変えられます**
(共有へ集めたいとき)。

### なぜなぜの追い方

1. **`error.log` を開く。** うまくいかなかったことだけが、理由と中身
   (traceback)つきで並んでいます。時刻と、仕事の番号 `[job=ab12cd34]` を拾う
2. **`app.log` をその番号で検索する。** 同じ仕事の筋道が頭から並びます ──
   そのとき何を使ったか(入力・出力先・ライン・参照用マスタ・停止内訳CSV)、
   1本ごとに「開きます → シート・作業日・ライン → 読めました(ページ/行/検算)」、
   最後に「書きました」
3. 起動そのものが怪しければ `launcher.log`

```
[job=ab12cd34] 設定: 入力=(ドラッグ) 出力先=D:\CSV出力 ライン=(自動) 参照用マスタ=… 停止内訳CSV=…
[job=ab12cd34] 変換開始 版=1.9.0 本数=7 ライン=(自動) 出力先=D:\CSV出力 確かめるだけ=False
[job=ab12cd34] 1/7 2025.07.16.xlsx 開きます 大きさ=49,793 バイト
[job=ab12cd34] 1/7 2025.07.16.xlsx シート=2025年7月15日_機側 作業日=2025年7月15日 ライン=機側→LS ※作業日を 2025/7/15 → … として読みました
[job=ab12cd34] 1/7 2025.07.16.xlsx 読めました ページ=4 行=27 集計の材料=32行 検算=8項目すべて一致…
[job=ab12cd34] 2/7 こわれ.xlsx 読めませんでした: xlsx ではありません(ZIPとして開けません)
    Traceback (most recent call last): …
```

**画面に出る理由と、ログに残る理由は同じ言葉**です ── 画面を閉じたあとでも
同じ言葉で追えます。

### ログの名前と置き場所 ── **どのツールが出したか分かるように**

共有の掃き出し先には、ほかのツールのログも集まります(`dbviewer`
`rneconverter` `nippou` …)。`app.log` のような名前だと、**取り出した
あとで開くまでどのツールのものか分かりません**。そこで**フォルダと
ファイル名の両方**にツール名を入れます:

```
\\共有\ログ\                            ← 設定の「ログの置き場所」で指すところ
    ExcelCsvConverter\                   ← ツール名のフォルダ(自動で作ります)
        ExcelCsvConverter_app.log        筋道
        ExcelCsvConverter_error.log      うまくいかなかったことだけ
        ExcelCsvConverter_launcher.log   起動
    dbviewer\ …                         ← ほかのツールのぶん
```

- **指した先がすでにツール名なら重ねません**(`…\ログ\ExcelCsvConverter`
  を指しても1段だけ)
- 端末の中(既定)は `%LOCALAPPDATA%\ExcelCsvConverter\logs\` ── **上の
  階層がすでにツール名**なので、フォルダは重ねず、名前だけ付けます
- ツール名は `config/app.json` の **`log_name`** です(現場の呼び名に
  合わせて変えられます)
- 「ログを開く」は、**いま書いているフォルダ**(ツール名の中)を開きます
- 名前を変える前に出した `app.log` などは**そのまま残します** ── 共有に
  あるほかのツールのファイルを触らないためです(不要なら手で消してください)

| 症状 | 見るところ |
|---|---|
| 何も起きない | `start.bat` で起動。黒い画面に理由が出ます |
| Python が見つからない | `Start.vbs` が先に確かめて知らせます(`start.bat` なら詳しく出ます) |
| 「すでに起動しています」 | 既存の画面を使うか、`stop.bat` で止めてから起動 |
| 「ポートを使えません」 | 別のアプリが `8741` を使っています。`config/app.json` の `server.port` を変更 |
| 待機画面のまま進まない | 45秒で見る場所が出ます。`launcher.log` を確認 |
| 「起動できませんでした」が出たまま残る | `stop.bat` で止まります(`--status` に理由が出ます)。放っておいても10分で閉じます |
| `stop.bat` のあとも Python が残る | 言う前に確かめるので、残っていれば「まだ残っています(PID …)」と出ます。そのPIDをタスクマネージャーで終了させてください(`runtime/instance.json` は手がかりとして残します) |
| ツールを動かしたまま PC を再起動した | **そのまま起動できます。** 残っていた目印は、ポートが空いていればその場で片付きます。`stop.bat` を打っても「残っていた目印を片付けました ── Start.vbs で起動できます」と出ます |
| 「ポートを使えません」が消えない | 別のプログラムが `8741` を使っています。`stop.bat` で**残った目印は片付きます**が、ポートは空きません ── `config/app.json` の `server.port` を変えてください。**番号が使い回された別の Python を終わらせることはしません**(番号と起動時刻の両方で見ます) |
| 「内訳」欄が空 | 停止内訳CSVの置き場所と参照用マスタの置き場所を確かめてください(どちらから読めたかは設定の下に出ます。記号と分類はマスタ無しでも出ます) |
| 集計が「拾える行がありませんでした」になる | VBAは**機側のシートだけ**を見ます(`A1が「集計」 かつ シート名に _機側`)。ほかのラインのブックなら、集計タブの**「機側以外のシートも読む」**を入れてください |
| 集計で拾われないブックがある | 集計タブの**「確かめるだけ」**で実行すると、1枚ずつ理由が出ます(シート名・A1・見出し・停止2枠・0行)。まとめて見るなら `python scripts/ブックを点検.py <フォルダ>` |
| 集計タブでCSVが「中身が分かりません」 | 材料になるのは**集計明細**のCSVです(日付フォルダごと入れれば選びます)。集計・計算内容のCSVは材料になりません |
| 裏に回って戻ると止まって見える | 戻った時点で**黙って取り直します**。ほかの画面で開かれていたときだけ、覆いが出ます |
| 窓を最小化(Excelを全画面に)して戻ったら「繋がりません」 | **終わらなくなりました**(1.11.0)。裏に回ったタブはブラウザが心拍を止めるので、居るものとみなします |
| スリープから復帰したら「繋がりません」 | **終わらなくなりました**(1.11.0)。眠っていた時間は無通信に数えません |
| ラインが決まらない | 設定の「ライン」で指定してください |

## 配るとき

フォルダごとコピーします。**書き込みは一切アプリ本体側へ行きません** ──
ログもキャッシュも設定も `%LOCALAPPDATA%` 配下です。だから共有フォルダに
置いて複数人が使っても、実行状態がぶつかりません。

アプリごとに決める値は `config/app.json` の1か所です。

```json
{ "app_id": …, "display_name": …, "version": …, "server": { "port": 8741 },
  "limits": { "max_files": 100 }, "monitoring": { "idle_exit_minutes": 30 } }
```

## デスクトップ版(1.12.0 から)

`ExcelCsvConverter.exe` を実行すると、ブラウザではなく**窓**で同じ画面が
開きます。**ポートを1つも使いません**ので、「ポートが使われていて起動
しない」がありません。落とされたブックは写さずにその場で読むので、
**1本の大きさの上限もありません**。

ブラウザ版は**予備として残します**。ただし**同時には動きません** ──
後から開いたほうが自分で止まります。

| 先に動いているもの | 後から開いたもの | 出るもの |
|---|---|---|
| デスクトップ版 | `Start.vbs` / `start.bat` | 「デスクトップ版が起動しています」(終了コード 5) |
| ブラウザ版 | `ExcelCsvConverter.exe` | 窓に理由が出て閉じます |

`stop.bat` は両方を止められます(`--status` でどちらが動いているか出ます)。
くわしくは [docs/デスクトップ版.md](デスクトップ版.md)。
