# 運用 ── 起動・停止・困ったとき

社内「汎用Webアプリ作成 基盤仕様書」に沿った作りです。ここでは**使う人と
面倒を見る人**が知っておくことだけを書きます。設計の理由はコードの先頭に
書いてあります。

## 使う

| すること | 実行するもの |
|---|---|
| 起動 | **`Start.vbs`**(これ1つだけ覚えてください) |
| 停止 | `stop.bat` ── 画面の「アプリを終了」でも同じです |
| 起動しないとき | `start.bat`(診断用。黒い画面に理由が出ます) |
| 環境だけ確かめたいとき | `start.bat --check`(起動せずに構成と状態を出します) |
| いま動いているか見たいとき | `stop.bat --status`(止めません) |
| 変換中でも止めたいとき | `stop.bat --force` |

`Start.vbs` を実行すると、**同じタブに**待機画面が出て、準備ができ次第
アプリ画面へ切り替わります。**秒数で切り替えてはいません** ── バック
エンドが「自分は誰で、準備ができた」と答えてから切り替えます。待機画面も
アプリ画面も同じアドレス(`http://127.0.0.1:8741/`)なので、**2枚目の
タブは開きません**。

## 画面は1枚だけです

2枚開けると、2つの画面が同じ作業状態を奪い合います(片方で開始、もう
片方で中止。片方で保存した設定を、もう片方は古いまま表示)。どちらが
本当か分からなくなるので、**開くこと自体をお断りします**。

| やったこと | どうなるか |
|---|---|
| 同じブラウザでもう1枚開く | 開いた側が「この画面は開けません」で止まります |
| 別のブラウザで開く | 同じく断ります(サーバ側の判定) |
| URLを直接打つ | 同じく断ります |
| `Start.vbs` をもう一度実行する | 「すでに起動しています」。2つ目は起動しません |
| **画面を再読込する** | 断りません(同じタブは持ち主のままです) |
| 画面を閉じて、開き直す | 開けます(閉じたあと10秒ほどで空きます) |

画面を閉じてしまってバックエンドだけ残った場合は、`Start.vbs` をもう一度
実行すると「開き直しますか?」と聞かれます。**はい**で元の画面に戻れます。

## 設定

画面上部の「設定」で決めて、保存すると**この端末に残ります**
(`%LOCALAPPDATA%\ExcelCsvConverter\data\settings.json`)。

| 項目 | 何を入れるか |
|---|---|
| 入力フォルダ | ブックが入っているフォルダ(「入力フォルダをそのまま読む」で使います) |
| 出力先フォルダ | **CSVを書く先。必須です。** 無ければ作ります |
| ライン | `LS` / `HVC` など。空ならシートの呼び名から当てます(`機側` → `LS`) |
| 参照用マスタの置き場所 | `伝送用ファイル.sqlite3` が入っているフォルダ。停止の「内訳」名に使います |

エクスプローラーの「パスのコピー」は引用符つき(`"C:\…"`)で入りますが、
そのまま貼って構いません ── 外してから使います。入力欄の下に**実際に
見に行く場所**と、そこがあるかどうかが出ます。

## 読ませかた

- **ドラッグで放り込む** ── 画面の枠へブックを落とします。フォルダごとでも
  構いません(中の `.xlsx` / `.xlsm` を拾います)。クリックで選ぶこともできます。
- **入力フォルダをそのまま読む** ── 設定した入力フォルダを読みます。
  押す前に「入力フォルダを数える」で本数を確かめられます。

**一度に100本まで。** 超えたぶんは受け取らず、その場で断ります
(`config/app.json` の `limits.max_files` で変えられます)。

> ブラウザは、放り込まれたファイルの本当の場所を教えてくれません(安全上の
> 決まり)。そのため、ドラッグのときだけ中身をいったん
> `%LOCALAPPDATA%\ExcelCsvConverter\work\intake` へ写してから読みます。
> 使い終われば消します。

**出したCSVはダウンロードしません。** 設定した出力先フォルダへ、この端末の
Pythonが直接書きます。「出力先を開く」でエクスプローラーが開きます。

## 変換中

進捗バーに「何本目か」「いま読んでいるファイル」「あとどれくらいか」が出ます。

- **中止**できるのは読み取り中だけです。CSVを書き始めてからは止めません
  ── 4本組のCSVを半分書いた状態で残すほうが危ないからです。
- 読み取り中に中止した場合、**CSVは1本も書きません**。
- ブラウザを閉じても変換は続きます。開き直すと、そのまま進み具合が出ます。
- 変換が終わって画面を30分開かないままにすると、バックエンドは自分で
  終わります(`monitoring.idle_exit_minutes`)。**変換中は終わりません。**

## 結果の見かた

| 印 | 意味 |
|---|---|
| ○ | 読めて、シート自身の合計とも合った |
| ! | 読めたが、**数がシートと合わない** ── 座標がずれているおそれがあります |
| × | 読めなかった(理由が同じ行に出ます) |

`!` は黙って通しません。どの直のどの数がいくつ違うかまで行に出ます。

## 困ったとき

まずログです。画面の「ログを開く」、または
`%LOCALAPPDATA%\ExcelCsvConverter\logs`。

| ファイル | 分かること |
|---|---|
| `launcher.log` | 起動の入口。環境・多重起動の判定・終了理由 |
| `app.log` | 画面の操作・変換の開始と終了・失敗 |

「起動前に失敗したのか、Webサーバが失敗したのか、変換で失敗したのか」が
この2本で分かれます。

| 症状 | 見るところ |
|---|---|
| 何も起きない | `start.bat` で起動。黒い画面に理由が出ます |
| Python が見つからない | `Start.vbs` が先に確かめて知らせます(`start.bat` なら詳しく出ます) |
| 「すでに起動しています」 | 既存の画面を使うか、`stop.bat` で止めてから起動 |
| 「ポートを使えません」 | 別のアプリが `8741` を使っています。`config/app.json` の `server.port` を変更 |
| 待機画面のまま進まない | 45秒で見る場所が出ます。`launcher.log` を確認 |
| 「内訳」欄が空 | 参照用マスタの置き場所が違います(記号と分類は出ます) |
| ラインが決まらない | 設定の「ライン」で指定してください |

## 配るとき

フォルダごとコピーします。**書き込みは一切アプリ本体側へ行きません** ──
ログもキャッシュも設定も `%LOCALAPPDATA%` 配下です。だから共有フォルダに
置いて複数人が使っても、実行状態がぶつかりません。

アプリごとに決める値は `config/app.json` の1か所です。

```json
{ "app_id": …, "display_name": …, "version": …, "server": { "port": 8741 },
  "limits": { "max_files": 100 }, "monitoring": { "idle_exit_minutes": 30 } }
```
