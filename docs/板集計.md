# 板集計 ── 日ごとのCSVを期間ぶん1つにまとめ、グラフにする

日報管理ツール(all-tools)が**日ごと・ラインごと**に書いたCSVを、
**期間を指して1本**にまとめます。まとめたものはそのままグラフになり、
CSV か Excel(グラフ付き)で出せます。

## 読むところ

設定タブの**板データ参照パス**の下を読みます。配下の形は向こうが
書いたままです。

```
<板データ参照パス>\
  L-1\                        ← ラインごとのフォルダ
    GW計算記録\               (読みません)
    印刷\                     紙(HTML)。読みません
    集計\
      2026.11\                年.月
        17\                   日
          集計_2026-11-17_L-1.csv      ← **これをまとめます**
          集計明細_2026-11-17_L-1.csv  (読みません)
          停止内訳_2026-11-17_L-1.csv  ← グラフの材料
  L-2\…
```

**このツールの変換タブが出す4本組も同じ形**です(同じコードで書いて
います)ので、変換して出したぶんもそのまま板集計にかけられます。

| | |
|---|---|
| **集計CSV** | 1日・1ライン・1直で1行。**これを期間ぶん縦に連結**します |
| 停止内訳CSV | 分類ごと・内訳ごとの停止。**グラフと Excel の別シート**に使います |
| 集計明細CSV | 読みません(1日12行×直×日数。まとめる相手ではありません) |

## 使い方

1. 設定タブで**板データ参照パス**を入れて保存します
2. 板集計タブを開くと、参照パス直下の**ラインが一覧**に出ます
   (集計フォルダを持たないラインは「集計フォルダがありません」と出ます)
3. ラインを選び(**複数選べます**)、期間を決めます
4. **グラフを出す** ── 画面で見るだけ。ファイルは書きません
5. **CSVで出す** / **Excelで出す(グラフ付き)** ── 設定タブの
   出力先フォルダへ書きます

```
板集計_L-1_2026-11-01-2026-11-30.csv     まとめた集計(1本)
板集計_L-1_2026-11-01-2026-11-30.xlsx    グラフ・集計・停止内訳・停止集計
```

**ダウンロードはしません**(このリポジトリの約束)。出力先フォルダへ、
この端末の Python が直接書きます。

## 出すもの

### 画面のグラフ

上から「どうだったか → どう動いたか → 何に時間を取られたか → で、数は」
の順に並べます。

| | |
|---|---|
| 大きな数字 | 合計重量・合計枚数・稼働率(日の平均)・停止合計 |
| 日別の推移 | 重量・稼働率・枚数。**ラインを2つ以上選ぶとライン別**に重ねます |
| 日別の枚数と累積枚数 | 棒(その日)と折れ線(累積)。**目盛りは左右で別** |
| 直別 | 重量・停止時間。棒は**直の色**(表・グラフ・Excel で同じ色) |
| 停止の輪 | 分類(4つ)と、項目ごと(長い順に6項目。残りはまとめ) |
| 表 | 日別の集計 / 停止の項目(**輪に出なかったものも全部**) |

### Excel(グラフ付き)

**VBAが出していた月別集計のブックに合わせてあります。**

| シート | |
|---|---|
| **グラフ** | 下の8種類(分類の数だけ円が増えます) |
| 集計 | **1行=1日。直は列**(`1直合計(枚)` `1直合計(t)` …) |
| 停止集計 | 分類ごとの内訳と回数・分(**円グラフの材料**) |
| 停止内訳 | 読んだままの停止 |
| 元データ | CSVで出すのと同じ行(直ごと)。数を追うため |

| グラフ | 形 |
|---|---|
| 直重量(t) | 棒。**直ごとに系列を分けます** |
| 直枚数(枚) | 棒。同上 |
| 停止・稼働時間(分) | 棒。作業・稼働と停止の分類 |
| 生産性(t/h) | 棒。直ごと |
| 稼働率(％) | 折れ線。**生産性とは別のグラフ**です |
| 累積枚数(枚) | 折れ線 |
| 直枚数・累積枚数推移 | 棒 + 折れ線。**累積は右の目盛り**(第2軸) |
| 「(分類)」(分) | **円**。分類の数だけ |

**1行=1日・直は列**にしているのが肝です。直を行に持ったままでは、
グラフの系列を直ごとに分けられません ── 「直別の重量」が直別に
ならないのはここが原因でした。

稼働率(90前後)と生産性(3前後)を1枚に重ねると、**生産性が床に
貼り付いて折れ線に見えません**。別のグラフにしてあります。
直枚数(数百)と累積枚数(数万)のように**どうしても1枚で見たいもの**は、
累積を右の目盛りへ移します(Excelの「第2軸に移動」と同じ形)。

系列の色は**自分で指しています**。Excel の既定の色は「テーマの色」から
来るので、テーマを入れていないブックでは**棒も扇も白く塗られて見えません**
(LibreOffice で開いて、軸だけ出て中身が空なことで分かりました)。
直の4色は Excel のグラフと同じ 青・赤・緑・紫です。

**画像ではなく本物のグラフ**です。期間を絞る・系列を足す・軸や凡例を
直す ── 受け取った人が Excel でできます(画像だとそこで手が止まります)。
追加ライブラリは使っていません(`converter/xlsx_out.py` が
`zipfile` と文字列で `.xlsx` を組み立てます)。

**CSVのときグラフは付きません**(表だけの形です)。

## ロットを探す

期間と**ロット№(頭の数桁だけでも)**で、集計明細CSVから当たった行を
出します。日報管理ツール(all-tools)の「ロットを探す」の移植です。

| 欄 | |
|---|---|
| **開始日・終了日** | 必須。はじめは板集計と同じ期間が入っています |
| **ロット№** | 必須。**前方一致**。全角・小文字・記号混じりでも当たります(`ｎ７１` → `N71`) |
| **ライン** | 「全ライン」か、参照パス配下のライン1つ |
| **探す** | 画面に出すだけ(**読むだけ**で何も書きません) |
| **CSVに出す** | 出力先フォルダへ書きます(**画面と同じ行**) |

出る列は紙の欄です ── 作業日・ライン・直・ページ・行・ロット№・
材・調質・厚×幅×丈・検入枚数・開始・終了・実績枚数・実績重量・
作業時間(分)・作業者・用途名・納入先。

### 探すところは3つ(上から強い順)

| 出どころ | 何が入っているか |
|---|---|
| **共有の日報データ** | 設定タブで `日報データ.sqlite3` を指したとき。**全ライン・全端末**の行で、日報管理ツールの「ロットを探す」と**同じ範囲**です |
| 集計明細CSV | 参照パスの `<ライン>\集計\…`。**集計から除いたページは入っていません** |
| 紙(印刷用HTML) | 参照パスの `<ライン>\印刷\…`。集計に無いページを補います |

上の出どころが持っているページは、下の出どころでは読みません(同じ行を
二重に出さないため)。「**どこから**」の列に、その行の出どころが出ます。

#### 共有の日報データ(いちばん確か)

日報管理ツールの各端末が「共有へ保存」で送っている先そのものです
(`T_日報ヘッダー_<ライン>` / `T_日報明細_<ライン>`)。**控え(LocalBackup)
ではありません** ── 控えはその端末の中の写しで、ほかの端末の行は
入っていません。

- **読むだけ**です(`?mode=ro` で開きます)。無いファイルを作らず、書けません
- **待たせません** ── 開くのも問い合わせも合わせて8秒で見切り、当たった
  行は2000行で止めます。共有に届かないときは、確かめるだけで何十秒も
  止まることがあります
- **読めなくても探すのをやめません。** 理由を画面に出して、集計明細CSVと
  紙で続けます
- **Access(.accdb)は読みません。** ロット№の比べ方(全角・小文字を
  揃えてから頭を比べる)は Access の SQL では書けず、表を丸ごと書き出す
  ことになります ── 日報管理ツール側も同じ線引きで読んでいません

### 「集計から除く」で外した作業者のロットも出ます

日報管理ツールには**「集計から除く」**があります(梱包資材マスタの表)。
除く作業者のいるページは**集計に入りません** ── 外れるのは集計を作る
ところ(`services/agg_exclude`)なので、**集計CSV・集計明細CSV・
停止内訳CSVの3本とも**からそのページが消えます。

ページそのものは消えず、**共有の日報データには残ります**(集計ではなく
日報そのものだからです)。共有を指していないときは、**紙(印刷用HTML)**
から補います ── 集計明細に無かったページの紙だけを開きます。

```
<参照パス>\L-1\集計\2026.11\17\集計明細_…csv   ← ふだんはこちら
<参照パス>\L-1\印刷\2026.11\17\印刷_…_1直_2.html  ← 集計に無いページ
```

| 「どこから」の列 | |
|---|---|
| **集計明細** | ふだんの行 |
| **印刷(集計から除く)** | 紙に「自動」の印がある ── 集計から除いた作業者のページ |
| **印刷(集計に無い)** | 印は無いが集計明細に出ていないページ |

- ファイル名に日付・ライン・直・ページが入っているので、**開く前に**
  「集計明細にあるページか」が分かります ── 除外が無ければ**1枚も
  開きません**
- 紙には**用途名・納入先・作業時間の欄がありません**(紙の印刷範囲の外)。
  空のまま出します ── 無い欄を埋めるより、無いと分かるほうが親切です
- 除いたページの時間は、共有へ送るときに**自動で割り振った値**です
  (打った値ではありません。紙に「自動」の印が付くのはそのため)
- 紙は**共有へ保存したとき・印刷したとき**に書かれます。どちらもして
  いないページは参照パスに無いので、出ません

### なぜ集計明細か

1行=1ロットで、紙の欄がそのまま入っているからです。集計CSVは直ごとの
合計なので、ロットの行がありません ── **集計明細が無い日は出ません**
(変換タブで出したぶんが参照パスに入っているか確かめてください)。

### 決まり

- **空欄は断ります。** 期間の全部を出しても、上限に当たって「多すぎる」と
  言うだけになります
- 並びは **作業日 → ライン → 直 → ページ → 行**(紙をめくる順)
- 画面は **200行**まで。超えたら先の200行だけ出して「桁を増やすか期間を
  絞ってください」と言います。**CSVも画面と同じ行**です ── 違うものが
  出ると、どちらが本当か分からなくなります
- CSVの1行目に**探した条件**(ロット№・期間・ライン・行数)を書きます。
  メールに添えた瞬間にフォルダから離れるので

## 決まりごと

### 列は名前で読みます。位置では読みません

all-tools は集計CSVに列を足します(`その他(分)` が増えました)。位置で
読むと、足された日から**静かに1列ずれます**。見出しの名前で拾い、
**知らない列は捨てずに後ろへ付けて**出します。

### 稼働率は出し直します

日の稼働率は、直ごとの数字の平均ではありません。

```
(1440分 × 直の数 − 停止合計) ÷ (1440分 × 直の数) × 100
```

直の平均にすると、**1直だけ動いた日と3直とも動いた日が同じ数字**に
なります(移植元 `logic/aggregation.day_rate_pct` と同じ出し方)。

### 読めなかったものは黙って捨てません

日のフォルダがあるのにCSVが無い・見出しが違う・読めない ── どれも
「その日が抜けたグラフ」になります。**理由を数えて画面に出し**、
Excel ではシートの頭にも書きます。

### 歯止め

一度に **400日**まで。日のフォルダの名前で絞るので、広い期間を指しても
読むのはその期間のCSVだけです。超えると断ります(ふつうは指定間違い)。

### ラインは一覧にあるものだけ

画面から来た字をそのままフォルダ名に使うと、`..\..` のような字で
**参照パスの外**を読ませられます。参照パス直下に実際にあるフォルダ名と
突き合わせて、無い名前は断ります。
