# デスクトップ版(Tauri/Rust)への移行 ── 事前の見通し

**結論から: いまの機能はすべて維持できます。** 業務の処理(変換・機側データ
集計・設定・ログ)は Python のまま動かし、**ポートを使う部分だけ**を外枠
(Rust/Tauri)に置き換えます。直しが要るのは**小さく数えられる5か所**です。

この文書は、移行を始める前の**確かめと計画**です。移行そのものはまだ
していません(この版では1行も動きを変えていません)。

参照した移行済みの実装: `ViVio-Hellon/python-web-tools`(VER4.8.134 /
`docs/デスクトップ版.md`)。同じ形に揃えます。

### ② Rust で書き直す値打ちがあるか → **業務の処理にはありません**

実物に近い大きさのブック(1冊 約100KB。実物は約50KB)で測りました:

| 仕事 | かかった時間 |
|---|---|
| 変換 100冊 → 4本組CSV | **1.17秒**(1冊 12ms) |
| 機側データ集計 100冊 | **0.45秒** |
| xlsx を開いて読むだけ(20冊) | 5ms(1冊 0.3ms) |

受け入れ上限は100本です。**上限いっぱいでも1〜2秒**で、現場の待ち時間は
共有フォルダの往復がほとんどです。ここを Rust で書き直すと、

- **CSVが日報管理ツールと1バイト違わない**という保証(`vendor/` を通す形)が
  崩れます ── これはこのツールの存在理由です(`VENDOR.md`)
- VBAと同じ結果を守る試験 **272件**が、この形で書かれています

得るものが1秒で、失うものが保証です。**移しません。**

## 2. いまの作り ── ポートはどこに居るか

```
Start.vbs / start.bat
  └─ start_app.py          環境の確認・多重起動の判定・待ち受け・ブラウザを開く
       ├─ launch_guard.py  ポート + /api/health で「すでに起動しているか」
       ├─ server.py        127.0.0.1:8741 で待ち受ける(http.server)
       ├─ boot_server.py   待機画面(本体ができるまで)
       └─ app/             dispatch(Request) → Response ← **ここにポートは無い**
            ├─ routes/     19経路(572行)
            ├─ static/js/  画面の操作(1,124行)
            └─ converter/  変換・集計・設定・ログ(4,917行)
                 └─ vendor/ 日報管理ツールの写し(12,837行。**触らない**)
```

**`app/` から下はポートを知りません。** 受け取るのは
`Request(method, path, query, body, headers)` という素のデータで、返すのは
`Response(status, body, content_type, headers)` です。だから外枠を
差し替えられます ── 参照実装(Flask/WSGI)より**こちらのほうが簡単**です
(WSGI への変換も `werkzeug` も要りません)。

## 3. 移行後の形 ── 各言語が得意なことをする

```
エクセル → CSV 変換器.exe(Rust / Tauri)      … src-tauri/
 ├─ 窓(WebView2)・終了の確認・多重起動の防止
 ├─ Python を子として起動・監視(落ちたら理由を窓に出す)
 ├─ 画面の要求(app://localhost/…)を Python の標準入力へ渡す
 └─ **放り込まれたファイルの本当のパス**を Python へ渡す(下記)
        │ 標準入出力(1件 = 見出し1行 + 本文)
        ▼
bridge.py(Python)                             … ポート無しの入口
 └─ app の dispatch を呼ぶだけ(待ち受けない)
        ▼
app/ converter/ vendor/(Python)               … 変換・集計・設定・ログ(変わらず)
app/static/js(JS)                             … 画面の操作(変わらず + desktop.js)
```

| 担当 | 何を | なぜ |
|---|---|---|
| **Rust** | 窓・起動・終了・多重起動・Python の監視・ファイルの受け取り | OS の窓とプロセスを扱うのが得意。`.exe` 1つで配れる |
| **Python** | 変換・機側データ集計・設定・ログ・画面の組み立て | 100冊で1〜2秒。日報管理ツールと同じCSVを守る試験272件がこの形 |
| **JS** | 画面の操作 | 今までどおり。窓まわり(終了・フォルダを開く)だけ外枠に頼む |

### ポートを使わない仕組み

- 画面は `app://localhost/`(Windows の WebView2 では `http://app.localhost/`)を
  読みます。**ネットワークを通りません**(外枠の中で受ける名前)
- 外枠はその要求を Python の標準入力へ渡し、標準出力から応答を受け取ります
- 守り(起動トークン・画面の取り合い・実行中の確認)は**そのまま生きます**

### デスクトップ版だけ良くなること(Rust に任せるから)

| | いま(ブラウザ版) | デスクトップ版 |
|---|---|---|
| ブックの受け取り | ブラウザが**中身をコピー**して送る → `work/intake` に写してから読む(1本 50MB まで) | 外枠が**本当のパス**を渡す → **コピーせずその場で読む。大きさの上限も無くなる** |
| フォルダを開く | Python が `os.startfile` | 同じ(変わりません) |
| 終了 | タブを閉じる・心拍が切れる → 自動終了の見張り | 窓を閉じる → 標準入力が閉じて Python も終わる(**取り残さない**) |

## 5. 直しが要るところ ── **5か所だけ**

| # | 何 | なぜ | 大きさ |
|---|---|---|---|
| 1 | **`Host` の確認に外枠の名前を足す** | いま `127.0.0.1` と `localhost` だけ通します。`app.localhost` は 400 になります(実際に確かめました) | 1行 + 試験 |
| 2 | **`Request` / `Response` を `server.py` から出す** | `app/__init__.py` が `server.py` を読むと `http.server` → `ssl` まで付いてきます。ポートを使わない道で HTTP の部品を読むのは筋が通りません(`converter/wire.py` へ) | 移すだけ(動きは変わらない) |
| 3 | **自動終了の見張りを窓に任せる** | 窓を閉じれば標準入力が閉じて Python も終わります。デスクトップ版では見張り(`idle_exit`)は要りません(ブラウザ版はそのまま) | 分岐1つ |
| 4 | **`window.close()` を外枠に頼む** | 窓は JS から閉じられません。「終了」の最後だけ外枠へ頼みます(`desktop.js`) | 小さいJS 1本 |
| 5 | **版の置き場所が3つになる** | `config/app.json` / `tauri.conf.json` / `Cargo.toml`。食い違うと分からなくなるので、**試験で縛ります** | 試験1件 |

**業務の処理(`converter/` `vendor/`)は1行も触りません。**

## 6. ブラウザ版とデスクトップ版を同時に動かさない

ご指示: **「どちらを後から開いても止まる」**。

```
runtime\instance.json   ブラウザ版の印(PID・プロセスの起動時刻・ポート・合言葉)
runtime\desktop.json    デスクトップ版の印(exeのPID・PythonのPID・起動時刻)
runtime\desktop.lock    デスクトップ版の多重起動止め(OSのファイルロック。外枠が握る)
```

| 後から開いたほう | どうなる |
|---|---|
| デスクトップ版(ブラウザ版が動いている) | 窓に「**ブラウザ版が起動しています。先にそちらを終了してください**」と出し、**自分が終わります**。ポートの応答(`/api/health`)と印の両方で見ます |
| ブラウザ版(デスクトップ版が動いている) | 「**デスクトップ版が起動しています**」と出して**起動しません**(ブラウザも開きません) |
| デスクトップ版をもう1つ | 新しく起動せず、開いている窓を前に出します |
| ブラウザ版をもう1つ | いまのまま(「すでに起動しています」。画面を開き直すか聞きます) |

**先に動いているほうは触りません。** 変換の途中で落とさないためです ──
止めたいときは `stop.bat`(両方を見て、動いているほうを止めます)。

デスクトップ版は**ポートを使わない**ので、見分けは印の
**PID + プロセスの起動時刻**で行います ── 1.11.3 で入れた
`launch_guard.judge_recorded` がそのまま使えます(番号の使い回しに強い)。
