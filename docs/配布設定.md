# 配布設定 ── 1台で決めた設定を、配った先の端末でそのまま使う

設定(入力元・出力先・参照用マスタ・停止内訳CSV・板データ参照パス・
ログの置き場所)は**端末ごとのローカル領域**に入ります
(`%LOCALAPPDATA%\ExcelCsvConverter\data\settings.json`)。
**ツールのフォルダをコピーしても付いて行きません。**

配った先で1台ずつ打ち直すのは手間で、打ち間違えると**別の場所を
読み書きする端末**ができます ── 出力先が空なら変換を始めるときに
断られますが、参照パスが1字違う端末は「集計が出ない理由の分からない
まま」使われます。

## 流れ

1. **1台で設定します**(設定タブ)
2. 設定タブの「**配布設定を書き出す**」── 配る項目を選べます
3. 起動用のファイルと同じ階層に `配布設定\` ができます

```
ExcelCsvConverter\
  Start.vbs  ExcelCsvConverter.exe  …
  配布設定\
    設定.json          配る値(選んだ項目だけ)
    はじめに読む.txt   何が入っているか・配った先で何が起きるか
```

4. **このフォルダを含めて**、ツールのフォルダをまるごとコピーして配ります
5. 配った先は、起動したときに `配布設定\` を読みます

## 上書きの決まり

**その端末にすでにあるものは読み込みません。**

| 配った先の状態 | どうなるか |
|---|---|
| その端末で打った値がある | **そのまま**(配布設定より強い) |
| まだ決まっていない(空) | 配布設定の値で埋めます |
| 前に配った値のまま | 配り直した**新しい値に置き換えます** |
| 読み込んだあとに端末で直した | **残します**(その端末で決めた値です) |

**空の値は「無い」と数えます。** 「既定に戻す」で空になった項目を
既存と数えると、配ったのに前のまま動く端末ができます。

揃えたいときは「**配布設定を読み込み直す**」── 端末で決めた値も
上書きします。

読み込んだ値は端末の中に控えます
(`%LOCALAPPDATA%\ExcelCsvConverter\data\distribution.json`)。
「前に配った値のまま」かどうかは、これで見分けています。

## 画面に出るもの

設定タブの配布設定の欄に、配れる項目と**いまの値**が並びます。
配布設定から入った値には「**配布設定の値**」の札が出ます ── 自分で
打った覚えのない値が入っている理由が分かるように。

## 配れるもの

| 項目 | 既定で選ぶ |
|---|---|
| 出力先フォルダ | ○ |
| 参照用マスタの置き場所 | ○ |
| 停止内訳CSVの置き場所 | ○ |
| 板データ参照パス | ○ |
| ログの置き場所 | ○ |
| 入力フォルダ | ― |
| ライン | ―(端末ごとに違うため) |

**空の項目は書き出しません。** 空を配ると、配った先の「まだ決まって
いない」と区別が付きません(埋める相手が無い)。

## パスワードは聞きません

日報管理ツールには管理者パスワードがあり、配布設定の操作に要ります。
このツールには管理者パスワードがなく、**書き出すのは自分の端末の設定
だけ**です ── 守るものが増えないので、鍵を増やしていません。

## 消すとき

「配布設定を消す」で `設定.json` と `はじめに読む.txt` を消します。
**この端末の設定はそのままです。** フォルダに人が置いたものがあれば、
フォルダは残します(こちらが作ったものだけ消します)。

## 困ったとき

| こうなった | なぜ | どうする |
|---|---|---|
| 配ったのに前のまま | 配布設定は**起動のときに読みます** | 閉じて開き直す。急ぐなら「読み込み直す」 |
| 1台だけ値が違う | その端末で打った値は上書きしません | その端末で「読み込み直す」 |
| 「配布設定を読めません」と出る | `設定.json` が壊れている・版が違う | 配る元で書き出し直す(**起動は止まりません**) |
| 書き出せない | ツールのフォルダが書き込み禁止(共有に置いている) | 書ける場所へ写してから書き出し、そのフォルダを配る |
